ROOT CAUSE

PSScriptRoot is a file-backed automatic variable.  R3 read R2 as text, patched
it, constructed a ScriptBlock and invoked that ScriptBlock.  The dynamically
constructed R2 code therefore had no script-file path and PSScriptRoot was an
empty string.

R2 attempted to evaluate:

  $RepoRoot = Split-Path -Parent $PSScriptRoot

PowerShell rejected the empty Path argument before R2 could bind the original
preparer blob or print any R2/original-preparer header.

The extension-cardinality correction itself succeeded.  This failure is an
execution-context anchor defect, not a replacement-cardinality defect and not a
VirtualBox or recovery-artifact failure.
