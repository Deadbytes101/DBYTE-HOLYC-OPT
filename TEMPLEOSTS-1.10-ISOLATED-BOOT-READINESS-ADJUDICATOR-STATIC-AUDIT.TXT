READINESS CLASSIFICATION

The adjudicator classifies:

  VDI first boot
    true only when boot1 is disk or harddisk, case-insensitive

  ISO attached
    true when the exact expected IDE-0-1 local ISO attachment is present

  network disabled
    true only when every machine-readable nicN value equals none

  clipboard disabled
    true only when the clipboard field equals disabled

  drag-and-drop disabled
    true only when the draganddrop field equals disabled

The actual boot-order and host-integration values are written to the external report.
No value is normalized into a safe state.  Unsafe or ambiguous values become explicit
requirements for the later boot-attempt copy.

DEFINED BOOT-COPY REQUIREMENTS

The report always requires:

  copying the sealed rehearsal Machine files to a second disposable root
  registering the copy in a new empty VBOX_USER_HOME
  bounded screenshot capture
  powering off the disposable boot copy
  revalidating the sealed rehearsal and default registry

It additionally requires, when observed:

  setting boot1 to disk on the boot copy
  detaching the ISO from the boot copy
  disabling all NICs on the boot copy
  disabling clipboard on the boot copy
  disabling drag-and-drop on the boot copy

The adjudicator never applies these corrections itself.

ADVERSARIAL JUDGMENT

A powered-off registration is not boot evidence.  An attached TempleOSTS ISO creates
a false-positive route unless the later boot attempt detaches it or otherwise proves
the VDI was the only boot source.  NAT, clipboard and drag-and-drop also violate the
intended offline disposable boot boundary and must be corrected only on a second copy.

The adjudicator intentionally denies direct start of the sealed rehearsal regardless
of the observed readiness values.  A later executor must create another disposable
copy, apply only the reported corrections, capture visual evidence, power the copy
off, and preserve all artifacts for semantic review.
