STATIC FINDING

The prepared bundle contains:

  running-vms.txt

The preparer writes an empty running inventory through Write-Utf8Lines.  For an
empty collection, that writer serializes one terminal newline.  Reading the file
with System.IO.File.ReadAllLines can therefore produce a string array containing
one empty-string element rather than an array with zero elements.

The verifier passes that captured array to Assert-LiveTarget.  Its Running
parameter declares:

  [AllowEmptyCollection()]
  [string[]]$Running

AllowEmptyCollection permits a zero-element array.  It does not permit an array
containing an empty-string element.  The verifier can therefore fail at parameter
binding before it evaluates that no target VM appears in the running inventory.

This is the same distinction already observed in the recovery-bundle preparation
path:

  is not the same PowerShell binding shape as
  collection containing an empty string
