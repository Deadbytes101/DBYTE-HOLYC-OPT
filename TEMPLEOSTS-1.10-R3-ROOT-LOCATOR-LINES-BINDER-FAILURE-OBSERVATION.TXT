ROOT CAUSE

The locator initializes a System.Collections.Generic.List[string], adds a blank separator row, and then passes that list to Add-Row. Add-Row declares its Lines parameter as Mandatory and strongly typed as List[string]. Windows PowerShell parameter validation rejects the collection because it contains an empty-string element before the function body is entered.

This is a locator helper binding defect. It does not establish any new fact about the missing R3 root beyond the previously observed Resolve-Path failure.

DECISION

Preserve the failed locator object. Do not edit it in place. Release a corrected R2 locator that keeps the read-only search logic unchanged while making Add-Row perform an explicit runtime type/null check instead of Mandatory collection-element validation.
