NO AUTOMATIC ROLLBACK

After startvm is issued, the launcher never attempts a compensating stop or poweroff.
This is intentional.
If post-start host observation fails, an automatic controlvm/poweroff would add a second mutation and could destroy boot evidence.
The actual VM state is preserved for subsequent inspection instead.
