OptPass789 ENTRY AND CONVERGENCE CONTRACT

Compiler/OptPass789.CPP states its pass-state contract directly:

  lx->pass==7  first time
  lx->pass==8  repeated until size stops shrinking
  lx->pass==9  final

LCCCompile enforces that contract:

  pass 7
    first sizing/finalization call with buf NULL and _dbg NULL

  pass 8
    repeated sizing calls with buf NULL and _dbg NULL
    code size may shrink
    code-size growth raises ST_OPT_INTERNAL_ERROR
    repetition stops when size no longer shrinks

  pass 9
    called after AOT or JIT output allocation
    receives the output buffer and optional debug pointer
    performs final emission

pass-7-only initialization before later sizing and emission work.  Therefore a
new pre-finalization action must run before the first pass-7 OptPass789 call.
