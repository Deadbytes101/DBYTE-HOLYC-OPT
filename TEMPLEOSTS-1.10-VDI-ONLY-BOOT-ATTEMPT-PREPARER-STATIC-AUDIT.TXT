ADVERSARIAL JUDGMENT

A copied VDI with an attached ISO is not a restore proof.
A copied VM with enabled host integration is not an isolated boot proof.
A prepared powered-off copy is still not a successful boot.

The script therefore stops after producing and verifying one corrected powered-off
copy.  A later verifier must seal that prepared copy before any one-time start can be
authorized.
