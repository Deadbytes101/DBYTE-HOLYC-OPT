MAKEALL ROUTE

Adam/Boot/InsBoot.CPP lines 125 through 139 define MakeAll.

The executable sequence is:

  Cd("/Compiler");
  if (Cmp("Compiler","Compiler",,':'))
    throw;

  Cd("/Kernel");
  if (Cmp("Kernel","Kernel",,':'))
    throw;

MakeAll therefore builds the compiler first and the kernel second.  It is a
whole-AOT wrapper, not the narrow first execution for the no-rewrite assertion.

MakeOSPrtBootInstall calls MakeAll and then continues into boot-loader and boot
installation work.  It is broader than the required compiler-only proof and is
not authorized for the first rebuild.

WRITE ORDER AND FAILURE SURFACE

CmpBuf enters CmpJoin with the resolved map path.  CmpJoin writes the map through
Who when compilation succeeds and cmp_do_not_write_to_dsk is false.

Cmp later constructs the binary module and writes Compiler.BIN.Z through
FileWrite.

Observed caller-visible order:

  compile and link project
  write Compiler.MAP.Z
  construct binary module and checksum
  write Compiler.BIN.Z
  return compiler error count

MakeAll throws when Cmp returns a nonzero error count.

No temporary output name, backup copy, rename-based commit, or explicit rollback
appears in the displayed Cmp, CmpJoin, MakeAll, or MakeOSPrtBootInstall call
chain.  This statement does not infer undocumented atomicity or non-atomicity
inside the underlying filesystem implementation.

Kernel/Dsk/Dsk1b.CPP shows FileWrite dispatching directly to the active RedSea or
FAT32 filesystem writer.  The displayed layer contains no extra compiler-output
transaction.

Risk:
  Compiler.MAP.Z may be written before Compiler.BIN.Z is committed by the caller
  sequence.  A guarded first build therefore requires pre-build copies and an
  independently verified restore procedure for both objects.
