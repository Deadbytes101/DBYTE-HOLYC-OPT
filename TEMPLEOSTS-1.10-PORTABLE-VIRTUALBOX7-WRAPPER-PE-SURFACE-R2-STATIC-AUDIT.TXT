READ-ONLY SCOPE

  the already-sealed wrapper binary inspection report.

No driver install/start operation is present.
No VM start is present.

PE HEADER CONTRACT

The inspector requires:
  DOS MZ signature;
  bounded e_lfanew;
  PE signature;
  bounded COFF header;
  section count 1..96;
  bounded optional header;
  PE32 or PE32+ optional-header magic;
  minimum optional-header size for the selected PE form;
  data directories fully inside SizeOfOptionalHeader;
  bounded section table;
  each non-empty raw section fully inside the wrapper bytes.

PE32+ ordinal-mask construction uses UInt64.Parse with HexNumber rather than a potentially ambiguous signed hexadecimal literal.

SECTION EVIDENCE

For every section the report records:
  index;
  name;
  virtual address;
  virtual size;
  raw offset;
  raw size;
  Shannon entropy;
  section characteristics.

The entry-point RVA is classified against the section virtual spans.
This is evidence for packed/high-entropy entrypoint analysis; it is not by itself a packer verdict.

IMPORT EVIDENCE

The inspector reads the import data directory through RVA-to-file-offset mapping.

Safety bounds:
  import descriptors <= 1024;
  import thunks per DLL <= 65536;
  each list must terminate explicitly;
  DLL names and import names require bounded NUL terminators;
  unmapped RVAs fail closed.

The report records:
  import DLL count;
  each DLL and its function count;
  all imported function names/ordinals;
  a focused interesting-import set.

Interesting imports include service/process/registry/dynamic-loader APIs such as:
  OpenSCManager*;
  CreateService*;
  OpenService*;
  StartService*;
  ControlService;
  DeleteService;
  CreateProcess*;
  ShellExecute*;
  WinExec;
  RegCreateKeyEx*;
  RegSetValueEx*;
  LoadLibrary*;
  GetProcAddress.

Presence is evidence of an available API route, not proof of the runtime path.
Absence is not treated as proof that the wrapper cannot reach such APIs indirectly.

RESOURCE / SECURITY / OVERLAY EVIDENCE

The inspector records:
  resource directory RVA/size;
  section containing the resource directory when uniquely resolvable;
  security directory file offset/size;
  end of mapped section/security file data;
  remaining overlay byte count.

It does not execute or extract resources.
