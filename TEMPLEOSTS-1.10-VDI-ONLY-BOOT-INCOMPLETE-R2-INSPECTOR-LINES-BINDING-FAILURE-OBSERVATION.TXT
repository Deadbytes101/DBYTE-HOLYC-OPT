PowerShell classification:
  ParameterBindingValidationException

FullyQualifiedErrorId prefix:
  ParameterArgumentValidationErrorEmptyStringNotAllowed

SOURCE CAUSE

The failed inspector creates:

  $Lines = [System.Collections.Generic.List[string]]::new()

and intentionally adds blank separator rows with:

  $Lines.Add('')

The same populated list is later passed to:

  Add-NodeAttributes -Lines $Lines ...

The failed helper signature is exactly:

  [Parameter(Mandatory = $true)][System.Collections.Generic.List[string]]$Lines

It does not include:

  [AllowEmptyCollection()]
  [AllowEmptyString()]

This is the same PowerShell mandatory-collection binding class previously observed with report arrays containing blank separator rows.
