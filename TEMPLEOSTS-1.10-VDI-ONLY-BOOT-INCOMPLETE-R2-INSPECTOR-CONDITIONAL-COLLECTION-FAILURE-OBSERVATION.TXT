STATIC COLLECTION REVIEW

The original inspector already materializes most multi-value objects with direct array subexpressions:
  @(...)

Examples include:
  target VDI registry rows
  target ISO registry rows
  attached ISO rows
  boot-order nodes
  network adapter nodes
  graphics nodes
  clipboard/drag nodes
  storage-device nodes
  machine files
  VBOX-like files
  isolated registry machine entries

Two collection assignments use a different form:

  $HomeFiles = if (...) {
      @( ... )
  }
  else {
      @()
  }

  $HomeDirectories = if (...) {
      @( ... )
  }
  else {
      @()
  }

PowerShell emits the result of an if statement through normal pipeline enumeration before assignment.
Therefore the inner @() does not guarantee that the receiving variable remains an array:
  zero emitted items can become $null
  one emitted item can become a scalar
  multiple emitted items become an array

The inspector later reads:
  $HomeFiles.Count
  $HomeDirectories.Count

Under Set-StrictMode -Version Latest, a null or scalar object without a Count property can produce the observed PropertyNotFoundStrict failure.
