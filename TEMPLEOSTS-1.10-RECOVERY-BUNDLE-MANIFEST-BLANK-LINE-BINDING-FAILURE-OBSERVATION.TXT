ROOT CAUSE

Write-Utf8Lines declares its Lines parameter as:

  [Parameter(Mandatory = $true)]
  [AllowEmptyCollection()]
  [string[]]$Lines

AllowEmptyCollection permits an array with zero elements.  It does not permit an
array containing empty-string elements.  The deterministic manifest deliberately
adds empty strings as section separators.  Windows PowerShell therefore rejects
Manifest.ToArray() during parameter binding before WriteAllText executes.

The correction is to add AllowEmptyString to the Lines parameter while retaining
AllowEmptyCollection.  This changes only the serialization parameter contract;
it does not change manifest contents, line ordering, hashes, copy sources,
VirtualBox state checks or recovery classification.
