R6 EXECUTABLE ANCHOR CLASSIFIER

R6 injects one function into dynamic R5 source:

  Get-ExactRepoRootAssignmentCount

The function parses supplied source using:

  System.Management.Automation.Language.Parser.ParseInput

It rejects every parser error before returning a result.

It searches the AST only for nodes satisfying:

  node is AssignmentStatementAst
  node extent text equals exactly:
    $RepoRoot = Split-Path -Parent $PSScriptRoot

The comparison is ordinal and case-sensitive.

Because the search is over AssignmentStatementAst nodes, the following cannot count:

  single-quoted strings
  double-quoted strings that do not execute as assignments
  here-string source templates
  base64 constants
  diagnostic messages
  regex patterns
  longer identifiers
  comments

The exact source object is blob-bound, and its executable assignment uses the exact
spacing and case required by the extent comparison.
