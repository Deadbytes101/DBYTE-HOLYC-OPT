ROOT CAUSE

The base verifier Convert-MachineReadable parser captures the raw key with:

    $Key = $Matches[1]

It strips surrounding quotes from values but does not strip surrounding quotes from keys.

For ordinary keys such as VMState this is harmless because the key is unquoted.
For storage attachment keys VirtualBox 7.0.12 emits:

    "IDE-1-0"="...Temple1.10.vdi"

Therefore the map contains the literal key "IDE-1-0" including quote characters, while the verifier requires IDE-1-0 without quote characters.

The probe independently normalized surrounding key quotes and recovered IDE-1-0, proving the schema mismatch.
