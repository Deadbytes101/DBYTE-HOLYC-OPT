ROOT CAUSE

R8's report format and report hash are internally consistent with blank separator rows.
The defect is only the collection parameter annotation used by three report helper functions:

  Get-ReportField
  Assert-ReportField
  Assert-Attempt

Each function declares a mandatory string-array Lines parameter without AllowEmptyString.
The helpers search only for exact key-plus-tab prefixes, so allowing blank elements does not weaken field cardinality or value comparison.

ADJUDICATION

  preserve R8 and bind its exact tree and local blob
  add AllowEmptyString to exactly the three Lines string-array parameters
  retain the mandatory collection contract
  retain exact report SHA256 binding

  retain fixed --clipboard-mode and --drag-and-drop selection
