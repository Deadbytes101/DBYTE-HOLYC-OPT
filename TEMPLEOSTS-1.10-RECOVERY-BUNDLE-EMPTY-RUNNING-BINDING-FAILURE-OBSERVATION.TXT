ROOT CAUSE

The preparer deliberately queries:

  VBoxManage list runningvms

A powered-off target correctly produces an empty string array.  Assert-LiveTarget
requires a mandatory string-array Running parameter but does not declare
AllowEmptyCollection.  Windows PowerShell therefore rejects the expected empty
array during parameter binding before the function can evaluate that the target
has zero running rows.

This is a parameter contract mismatch.  It is not evidence that the target VM
was running and it is not evidence that the powered-off state changed.
