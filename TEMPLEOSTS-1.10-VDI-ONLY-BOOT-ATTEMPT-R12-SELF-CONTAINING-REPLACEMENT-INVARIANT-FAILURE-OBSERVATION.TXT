ROOT CAUSE

R12's generic replacement helper verifies:
  old count before equals ExpectedOldCount
  new count before equals zero
  old count after equals zero
  new count after equals ExpectedOldCount

The third condition is valid only when New does not itself contain Old.
The policy injection is deliberately self-containing: New contains Old exactly once.

The correct generic invariant is:
  old_occurrences_per_new = exact ordinal count of Old inside New
  expected_old_after = ExpectedOldCount * old_occurrences_per_new
  observed old_after must equal expected_old_after
  observed new_after must equal ExpectedOldCount

For ordinary replacements where New does not contain Old:
  old_occurrences_per_new = 0
  expected_old_after = 0

For this policy anchor replacement:
  ExpectedOldCount = 1
  old_occurrences_per_new = 1
  expected_old_after = 1
