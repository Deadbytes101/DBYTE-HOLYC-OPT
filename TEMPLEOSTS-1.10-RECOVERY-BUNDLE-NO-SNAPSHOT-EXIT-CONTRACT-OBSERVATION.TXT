ROOT CAUSE

The preparer routes every VBoxManage read through one generic helper that throws
on any nonzero exit code.  In this VirtualBox build, the snapshot-list command
represents the valid no-snapshot state by returning a nonzero exit code together
with the exact sentinel text:

  This machine does not have any snapshots

The existing code therefore rejects the expected zero-snapshot state before it
can convert the inventory to zero SnapshotName, SnapshotUUID or SnapshotNode
rows.

This is an exit-contract mismatch.  It is not evidence that a snapshot exists,
that the target started, or that the powered-off state changed.
