CLASS

NATIVE HOLYC OPTIMIZER EXTENSION.
NOT A PORT.
NOT A TRANSPILER.
NOT A REPLACEMENT COMPILER.

AUTHORITY

Terry A. Davis-authored source and matching historical packages are the
semantic authority.

DBYTE-HOLYC-TOOLS is the read-only resource layer for exact package identity,
archive extraction, source maps, compiler archaeology, and accepted evidence
boundaries.  It is not linked into the compiler.

RARE-CORPUS RULE

The optimizer target must come from a byte-identified original Terry package.
A common public source mirror, reconstruction, normalized copy, later fork, or
community port is not an optimizer target.

CURRENT SEAM STATUS

The later TempleOS 5.03 source shows a candidate seam after OptPass6 and before
OptPass789A.  That is archaeology only.  It is not authorization to patch the
1.10 internal compiler.

The real 1.10 seam must be rediscovered in the expanded TempleOSTS compiler
bytes and sealed by path, byte count, and SHA256 before code is written.

MODEL

Operate directly on the original compiler intermediate code found in the rare
corpus.  Build temporary analysis tables only when needed.  Discard them after
the function is handled.  Preserve the original parser, intermediate code,
register model, fix-ups, JIT path, AOT path, and x86-64 backend.
