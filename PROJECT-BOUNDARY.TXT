AUTHORITY

Terry A. Davis-authored source and matching historical packages are the
semantic authority.

DBYTE-HOLYC-TOOLS is the read-only resource layer for exact package identity,
archive extraction, source navigation, compiler archaeology, and accepted
evidence boundaries.  It is not linked into the compiler.

RARE-CORPUS RULE

The optimizer target must come from a byte-identified original Terry package.
A common public source mirror, reconstruction, normalized copy, later fork, or
community port is not an optimizer target.

DISCOVERY MODEL

Hash every expanded file before selecting a compiler candidate.  Search exact
historical bytes for compiler-like paths and function names.  Count later-era
anchors as observations, not requirements.  Manually adjudicate the compiler,
pass pipeline, and seam from byte-identified files before any source copy or
rewrite is created.

MODEL AFTER SEAM SEALING

Operate directly on the original compiler intermediate form found in the rare
corpus.  Build temporary analysis tables only when needed.  Discard them after
the function is handled.  Preserve the original parser, intermediate form,
register model, fix-ups, JIT path, AOT path, and x86-64 backend.
