SEALED LOAD BOUNDARY

Kernel boot loads:

  Cd("/Compiler");
  Load("Compiler",LDF_SILENT);

Load resolves Compiler.BIN.Z, checks module alignment and TEMPLEOS_XSUM, and
executes both loader passes.

Adam package initialization later loads the map through:

  MapFileLoad("::/Compiler/Compiler");

Compiler.MAP.Z is mapping data and is not the boot compiler module.
