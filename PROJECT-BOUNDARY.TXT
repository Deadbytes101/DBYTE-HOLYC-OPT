SEALED PASS CONTRACTS

LCCHeaderPut preserves the existing trace boundary and always writes the
supplied pass value into lx->pass.

OptPass6 mutates the existing intermediate-code chain in place and finalizes the
displayed register and clobber state used by following backend work.

OptPass789 uses pass 7 for first-time finalization and sizing, pass 8 for
repeated sizing until stable, and pass 9 for final emission.
