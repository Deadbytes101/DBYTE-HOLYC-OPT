NATIVE PROCESS CONTRACT

The probe uses:

  System.Diagnostics.Process
  System.Diagnostics.ProcessStartInfo

For every native invocation it sets:

  UseShellExecute false
  CreateNoWindow true
  RedirectStandardOutput true
  RedirectStandardError true
  StandardOutputEncoding UTF-8
  StandardErrorEncoding UTF-8

It reads stdout and stderr asynchronously and separately.
It waits at most fifteen seconds for each native process.
A timed-out process is killed and the probe fails closed.

The probe does not use:

  native-command 2>&1 through the PowerShell pipeline
  ErrorActionPreference relaxation
  LASTEXITCODE as an indirect global value

The exit code is read directly from the completed Process object.
