ROOT CAUSE

R3 used a raw substring count:

  [regex]::Escape('$PSScriptRoot')

The R2 source contains one executable exact variable token:

  $RepoRoot = Split-Path -Parent $PSScriptRoot

It also contains textual strings whose prefixes include the same characters:

  $PSScriptRootReferences
  [regex]::Escape('$PSScriptRoot')

The variable name $PSScriptRootReferences begins with the substring $PSScriptRoot.
Therefore the raw textual count returned five even though the exact executable
PSScriptRoot variable token occurred only once.

The exact repository-root anchor count remained one:

  anchor=1

This proves the failure was caused by over-broad textual token classification, not
by multiple executable repository-root anchors.
