ADJUDICATION

The sealed bundle VBOX preserves the original machine UUID and media UUID
references.  The current VirtualBox registry already contains the same machine
UUID and the same VDI UUID.  Registering the bundle side by side in the current
registry would therefore collide with live registered identities.

The sealed bundle itself is immutable evidence.  VirtualBox may write state or
normalization changes to a registered VBOX.  The sealed source VBOX must never
be registered, rewritten or booted directly.

The VBOX DVD media location resolves to the live absolute ISO path rather than
the bundle-local ISO copy.  Any isolated rehearsal must rewrite only a
disposable VBOX copy so its DVD media location resolves to the disposable ISO.

An in-place cold restore route has the required original machine and media
identities, but executing it would replace or alter live registered artifacts.
It remains defined but not authorized.

ONE DECISION

Prepare an isolated disposable rehearsal environment only.

The preparation route must:

  preserve the sealed bundle and all prior evidence unchanged
  require a new empty rehearsal root
  require a new empty VBOX_USER_HOME
  copy VBOX, VDI and ISO to disposable paths
  rehash all copies against sealed identities before any rewrite
  rewrite only the disposable VBOX ISO location to the disposable ISO path
  keep the disposable VDI bytes and UUID unchanged
  use VBoxManage only with the isolated VBOX_USER_HOME environment
  verify the isolated registry is empty before registration
  register only the disposable VBOX in the isolated registry
  require the isolated VM to remain powered off
  require zero snapshots and zero shared folders
  never start the VM
  never touch the current VirtualBox registry
  never modify live or sealed bundle files
  write a preparation report outside all protected roots

Preparation is not boot proof and is not restore proof.
